# Map fonts

`semibold/0-255.pbf` holds the glyphs MapLibre draws the cluster counts with (the map style's `glyphs` URL points here).

It is Open Sans Semibold (Apache License 2.0) from the MapLibre demo glyphs, `https://demotiles.maplibre.org/font/Open%20Sans%20Semibold/0-255.pbf`, cut down to `0123456789.k+` to be 5 KB instead of 77 KB. A count never needs another character. The folder is called `semibold` so the URL has no spaces, and the map asks for that name in `text-font`.
